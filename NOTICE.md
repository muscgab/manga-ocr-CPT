- 两个模型的权重都由 [kha-white/manga-ocr-base](https://huggingface.co/kha-white/manga-ocr-base)（mangaOCR）初始化，其模型卡声明为 Apache License 2.0（许可全文同 `LICENSE`），并列出 Manga109-s 为训练数据。按其配置，mangaOCR 的编码器来自 facebook/deit-base-patch16-224，解码器来自 cl-tohoku/bert-base-japanese-char-v2。本仓库的推理代码为重写实现，不依赖 manga-ocr 包或 `transformers`。
- 继续预训练的真实样本来自 [JustANormalTinkerer/animetext-ocr](https://huggingface.co/datasets/JustANormalTinkerer/animetext-ocr)（revision `9c70c6b`），数据集声明为 CC BY-NC-SA 4.0。

- 合成训练数据由项目渲染器生成。本仓库不含训练图片、字体文件或 AnimeText-OCR 图片。
- JMangaBench_Read 的候选池与评测集图片均未用于训练。
- `samples/` 中的 8 张示例裁图取自 [JMangaBench_Read v1.3](https://github.com/muscgab/JMangaBench_Read)（CC BY-NC-SA 4.0），原作为独立画师公开发布的作品，文件名即 Read 中的框编号。
- `accel/` 中的脚本用于运行 [Hayai v2.5 Nova](https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.5-nova)（JustANormalTinkerer，Apache License 2.0）和 [PaddleOCR-VL-For-Manga](https://huggingface.co/jzhang533/PaddleOCR-VL-For-Manga)（jzhang533，Apache License 2.0）。脚本调用这两个模型自带的代码，并用相同的运算重新实现了其中一部分（Nova 的视觉编码与解码步、Paddle 的解码层调用与预处理）。本仓库不含这两个模型的权重。`gpu_resize.py` 按 Pillow 的算法（libImaging/Resample.c）在 GPU 上重新实现了双三次缩放。
- 致谢：[mangaOCR](https://github.com/kha-white/manga-ocr)（结构与初始权重）、AnimeText 与 AnimeText-OCR（真实训练裁图）、Real-ESRGAN（假名字形放大）。

## English

- The code in this repository is licensed under Apache License 2.0 (`LICENSE`). This repository contains no model weights; the weights of the two models (manga-ocr-base-CPT-flex, manga-ocr-base-CPT) are in their own Hugging Face / ModelScope repositories under CC BY-NC-SA 4.0; commercial use requires separate permission.
- The weights of both models are initialised from [kha-white/manga-ocr-base](https://huggingface.co/kha-white/manga-ocr-base) (mangaOCR), whose model card declares Apache License 2.0 (full text as in `LICENSE`) and lists Manga109-s as training data. According to its configuration, the mangaOCR encoder comes from facebook/deit-base-patch16-224 and the decoder from cl-tohoku/bert-base-japanese-char-v2. The inference code in this repository is a re-implementation and does not depend on the manga-ocr package or `transformers`.
- Real samples for the continued pre-training derive from [JustANormalTinkerer/animetext-ocr](https://huggingface.co/datasets/JustANormalTinkerer/animetext-ocr) (revision `9c70c6b`), declared under CC BY-NC-SA 4.0.
- The images of that dataset come from AnimeText ([arXiv 2510.07951](https://arxiv.org/abs/2510.07951)). The real kana glyphs used by the synthetic handwriting were also cut from AnimeText images and upscaled 4× with [Real-ESRGAN](https://arxiv.org/abs/2107.10833) (RealESRGAN_x4plus_anime_6B); this repository does not contain those glyphs.
- Synthetic training data was generated by the project renderer. This repository contains no training images, font files or AnimeText-OCR images.
- No image from the JMangaBench_Read candidate pool or benchmark was used for training.
- The 8 example crops in `samples/` are taken from [JMangaBench_Read v1.3](https://github.com/muscgab/JMangaBench_Read) (CC BY-NC-SA 4.0); the original works were published online by independent artists. File names are the box IDs in Read.
- The scripts in `accel/` run [Hayai v2.5 Nova](https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.5-nova) (JustANormalTinkerer, Apache License 2.0) and [PaddleOCR-VL-For-Manga](https://huggingface.co/jzhang533/PaddleOCR-VL-For-Manga) (jzhang533, Apache License 2.0). They call the models' own code and re-implement parts of it with the same operations (Nova's vision encoder and decoding step; Paddle's decoder-layer calls and preprocessing). This repository contains no weights of these models. `gpu_resize.py` re-implements Pillow's bicubic resize (libImaging/Resample.c) on the GPU.
- Acknowledgements: [mangaOCR](https://github.com/kha-white/manga-ocr) (architecture and initial weights), AnimeText and AnimeText-OCR (real training crops), Real-ESRGAN (upscaling of the kana glyphs).
